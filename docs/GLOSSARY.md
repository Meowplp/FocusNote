# FocusNote terminology

| Term | Meaning |
| --- | --- |
| Day / Daily list | A dated checklist; creating another day never deletes this one. |
| Task | A checkbox item with a focus plan. |
| To Do | Daily section for tasks with Pomodoro plans. |
| To Remember | Daily section for plain checkbox notes, without Pomodoro features. |
| Note | A manually checked To Remember item; never a focus task. |
| Planned Pomodoros | Target number of completed focus sessions for a task. |
| Pomodoro / Focus session | One timed focus attempt; counted as completed only after its full active duration. |
| Round | The task's current planned batch of Pomodoros; finishing it offers the task's long break. |
| Short break | Rest between Pomodoros; never counted as focus. |
| Long break / Task break | Configurable rest after the task's final planned Pomodoro; replaces the short break at that boundary. |
| Actual focus time | Active time spent focusing, including partial cancelled attempts. |
| Start / Pause / Resume | Begin, temporarily stop, or continue the same countdown. |
| Switch Task | Cancel the current attempt and open another task. |
| Reset Session | Cancel the current attempt and prepare a full-duration replacement; preserve prior completions. |
| Complete Task | Automatically check it off at the final planned focus, before its long break; checking it manually early remains possible. |
| Undo | Reverse a task completion without automatically restarting a timer. |
| Back to List | Show the checklist; navigation alone does not cancel focus. |
| Keep on Top | Pin the timer above ordinary windows. |
| Add Task | Create a checkbox item, not a daily list. |
| Add Note | Create a plain To Remember checkbox note (⇧⌘N). |
| New Day… | Choose/open a dated list; header plus opens or creates today. |
| Export… | Save a Markdown copy without removing local data. |
| Settings | Persistent timer defaults and behavior preferences. |
| Continue Focusing | Begin another round after the current round target. |
| Start Break / Skip Break | Begin or omit the offered rest. |
| Retry | Attempt a failed save again while retaining input. |
| All done | Brief checkmark celebration after the final long break ends or is skipped; the timer closes and the To Do list opens automatically. |
| Today | The active daily checklist, kept until the next launch/main-window reopen detects a later system date. |
| History | Read-only saved lists with task/note states, focus plans, and session details. |
| Analytics | One dashboard: streaks, plan-completion heatmap, and weekly planned/actual hours. |
| Plan consistency | Heatmap of actual focus ÷ planned focus; green above 80%, light green above 50% up to 80%, neutral at/below 50%, outlined when no plan exists. |
| Average planned / Average actual | Daily means over the same elapsed calendar days in the selected week; completed weeks include all seven days. Future days do not dilute current-week averages. |
| Focus time / Locked-in time | Actual active focus, including partial attempts; excludes breaks, pauses, sleep, and offline time. |
| Planned focus | Sum of task session targets × focus duration; frozen when the list is archived. |
| Locked-in day | A calendar day with at least 10 minutes of actual focus. |
| Current streak | Consecutive locked-in days; today does not break yesterday's streak until its day ends. |
| Best streak | Longest recorded run of qualifying calendar days, including weekends. |
| Rollover | Save/archive the previous active day and activate today's list before playing the fold animation. |
| Copy Unfinished Tasks to Today | Create fresh unchecked tasks with the same settings, no earned progress, and a copied-from reference. |
| Copy Unchecked Notes to Today | Separately copy unchecked plain notes; do not affect Pomodoros. |
| Approximate placement | A preserved duration whose exact active clock intervals are unavailable, attributed to its recorded start date/hour. |
